# Maturnitni_prace_heslator
Maturitní práce na téma Heslátor: interaktivní aplikace na rozbor, ukládání a generování hesel.


Todo/zápisky:
 - zachovat čas, hodnotu pro heslo brát z výsledných bitů. Pokud je slovo ve slovníku tak brát hodnotu menší jak 1s. Rychlost brát velkou - cca výkon 4 grafik 40. verze
 - odhadování bitů dle Souhrady je gut. 
 - fixnout guest login - prostě tam jebnout key a použít stejnou classu jako u normálního loginu
 - fixnout aby se breakla classa rozbor pokud je prazdne heslo
